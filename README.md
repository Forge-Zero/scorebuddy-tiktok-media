# ScoreBuddy TikTok media

Public delivery of prepared MP4 clips for the ScoreBuddy Buffer publishing workflow.
Only selected videos are copied to `videos/<sha256>.mp4`. Source metadata,
publication state, credentials and source projects belong in private repositories.

Files here are publicly downloadable, including before their scheduled TikTok post.
Keep the repository public and preserve its Git history while a Buffer post is pending.
The publisher verifies each commit-pinned raw URL before scheduling a post.
